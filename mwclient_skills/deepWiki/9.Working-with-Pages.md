## The Page Class

`Page` is defined in [mwclient/page.py L12-L692](https://github.com/mwclient/mwclient/blob/47ea5b29/mwclient/page.py#L12-L692)

 and is the primary object representing a single wiki page. It holds both the page's metadata (fetched at instantiation) and provides methods for reading content, making edits, and querying associated data.

Two subclasses extend `Page`:

| Class | Module | Namespace |
| --- | --- | --- |
| `Page` | `mwclient/page.py` | All others |
| `Image` | `mwclient/image.py` | File / Image (ns 6) |
| `Category` | `mwclient/listing.py` | Category (ns 14) |

`Image` inherits from `Page`. `Category` inherits from both `Page` and `GeneratorList`.

## Page Properties

After construction, the following instance attributes are populated from the API response:

| Attribute | Type | Source field | Notes |
| --- | --- | --- | --- |
| `name` | `str` | `title` | Full title including namespace prefix |
| `namespace` | `int` | `ns` | Integer namespace ID; 0 = main |
| `exists` | `bool` | absence of `missing` | `False` if the page does not exist |
| `revision` | `int` | `lastrevid` | Latest revision ID; 0 if new |
| `pageid` | `int` or `None` | `pageid` | MediaWiki page ID; `None` if page doesn't exist |
| `protection` | `dict` | `protection` | Maps action string → `(level, expiry)` tuple |
| `redirect` | `bool` | `redirect` | `True` if the page is a redirect |
| `length` | `int` or `None` | `length` | Page size in bytes |
| `touched` | `time.struct_time` or `None` | `touched` | Timestamp of last cache invalidation |
| `contentmodel` | `str` or `None` | `contentmodel` | e.g. `'wikitext'`, `'json'` |
| `pagelanguage` | `str` or `None` | `pagelanguage` | Language code e.g. `'en'` |
| `restrictiontypes` | `list` or `None` | `restrictiontypes` | Which actions can be protected |

## Checking Permissions

`Page.can(action)` checks whether the currently authenticated user has permission to perform an action on the page [mwclient/page.py L148-L161](https://github.com/mwclient/mwclient/blob/47ea5b29/mwclient/page.py#L148-L161)

It works by inspecting `self.protection` for the given action, resolving `'sysop'` to `'editprotected'`, and checking whether that right is present in `self.site.rights`.

This is used internally by `text()`, `_edit()`, `move()`, and `delete()` before issuing any API calls.

## protection Attribute Structure

The `protection` dict maps each restricted action to a tuple of `(level, expiry)`:

```
{
    'edit':   ('autoconfirmed', 'infinity'),
    'move':   ('sysop', '2025-01-01T00:00:00Z'),
}
```

Built from the `inprop=protection` response at [mwclient/page.py L81-L85](https://github.com/mwclient/mwclient/blob/47ea5b29/mwclient/page.py#L81-L85)

## Token Acquisition

`Page.get_token(type, force=False)` delegates to `self.site.get_token(type, force, title=self.name)` [mwclient/page.py L163-L164](https://github.com/mwclient/mwclient/blob/47ea5b29/mwclient/page.py#L163-L164)

 Token caching is managed by `Site`. The `force=True` flag bypasses the cache and re-fetches. This is called internally for edit, move, and delete operations.

## Passing Pre-fetched Info

When pages are returned by a listing (e.g., iterating `site.allpages()`), the `info` dict is already available from the generator response. In that case, the `Page` constructor receives it directly via the `info` parameter and skips the API call. This is the standard pattern used by `GeneratorList.__next__()` in `mwclient/listing.py`.

## __repr__

The string representation of a `Page` object is:

```
<Page object 'Main Page' for <Site object ...>>
<Image object 'File:Example.jpg' for <Site object ...>>
<Category object 'Category:Python' for <Site object ...>>
```

The class name in the repr is dynamic (`self.__class__.__name__`), so subclasses display correctly [mwclient/page.py L129-L130](https://github.com/mwclient/mwclient/blob/47ea5b29/mwclient/page.py#L129-L130)
