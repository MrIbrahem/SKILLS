### Parameters

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `section` | `int`, `str`, or `None` | `None` | Section number or `T-<number>` identifier. Fetches only that section's wikitext. |
| `expandtemplates` | `bool` | `False` | If `True`, expands all templates in the returned text. Requires an extra API call on MediaWiki ≥ 1.32. |
| `cache` | `bool` | `True` | Use the instance-level `_textcache` dict. Pass `False` to force a fresh API call. |
| `slot` | `str` | `'main'` | Content slot name (MediaWiki ≥ 1.32 multi-content revisions). Passed as `rvslots` in the underlying API call. |

### Behavior Details

**Permission check:** The first thing `text()` does is call `self.can('read')`. If the current user lacks the `read` right, `InsufficientPermission` is raised immediately.

**Non-existent page:** If `self.exists` is `False`, `text()` returns an empty string `''` without making an API call.

**Caching:** The in-memory cache is stored in `self._textcache` [mwclient/page.py L49](https://github.com/mwclient/mwclient/blob/47ea5b29/mwclient/page.py#L49-L49)

 a dict keyed by `hash((section, expandtemplates))`. A cache hit returns the stored value without any API call. The cache is cleared automatically after any successful edit operation [mwclient/page.py L335](https://github.com/mwclient/mwclient/blob/47ea5b29/mwclient/page.py#L335-L335)

**Content retrieval:** Internally, `text()` calls `self.revisions()` with `prop='content|timestamp'` and `api_chunk_size=1` [mwclient/page.py L201-L202](https://github.com/mwclient/mwclient/blob/47ea5b29/mwclient/page.py#L201-L202)

 Setting `api_chunk_size=1` (not `max_items`) avoids fetching 50 revisions unnecessarily — only one revision's content is needed.

**Slot handling:** For MediaWiki ≥ 1.32, the API response places content inside `rev['slots'][slot]['*']`. For older wikis, the legacy `rev['*']` key is used. `text()` checks both paths [mwclient/page.py L205-L208](https://github.com/mwclient/mwclient/blob/47ea5b29/mwclient/page.py#L205-L208)

**Template expansion:** The `rvexpandtemplates` revision API parameter was removed in MediaWiki 1.32. When `expandtemplates=True`, `text()` first fetches raw wikitext, then makes a second call to `self.site.expandtemplates(text)` [mwclient/page.py L218](https://github.com/mwclient/mwclient/blob/47ea5b29/mwclient/page.py#L218-L218)

 When `expandtemplates=False`, `self.edit_time` is set to the current time (used by `_edit()` for conflict detection).

**Side effects:** On success, `self.last_rev_time` is updated with the revision timestamp. This timestamp is used by `_edit()` as the `basetimestamp` parameter to detect edit conflicts.

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `startid` | `int` | `None` | Revision ID to start listing from. |
| `endid` | `int` | `None` | Revision ID to stop listing at. |
| `start` | `str` | `None` | ISO 8601 timestamp to start from. |

| `expandtemplates` | `bool` | `False` | Sets `rvexpandtemplates=1`. Only effective on MediaWiki < 1.32. |
| `section` | `str` | `None` | If `prop` includes `content`, restricts to this section. |
| `diffto` | `int` | `None` | Revision ID (or `"prev"`, `"next"`, `"cur"`) to diff each revision against. |
| `slots` | `str` | `None` | Content slot (MediaWiki ≥ 1.32). Silently dropped for older wikis. |
| `uselang` | `str` | `None` | Language for parsed edit comments and localized messages. |
| `max_items` | `int` | `None` | Maximum total revisions to yield across all pages. |
| `api_chunk_size` | `int` | `50` | Number of revisions to fetch per API request. |

### Return Value

`revisions()` returns a `mwclient.listing.RevisionsIterator` instance [mwclient/page.py L671-L674](https://github.com/mwclient/mwclient/blob/47ea5b29/mwclient/page.py#L671-L674)

 Each iteration yields a `dict` containing the fields specified by `prop`. For example, with `prop='ids|timestamp|flags|comment|user'` (the default), each dict contains keys like `revid`, `parentid`, `user`, `timestamp`, `comment`, etc.

For more detail on pagination mechanics, `max_items`, `api_chunk_size`, and `RevisionsIterator` internals, see [Iteration and Pagination](/mwclient/mwclient/5-iteration-and-pagination).

### Compatibility note for slots

If `slots` is passed and the connected wiki is running MediaWiki < 1.32, the `rvslots` parameter is silently removed from the API call [mwclient/page.py L659-L661](https://github.com/mwclient/mwclient/blob/47ea5b29/mwclient/page.py#L659-L661)

 This prevents an API error on older wikis.

## Redirect Resolution

The `Page` class exposes two methods for dealing with redirects. The `page.redirect` boolean attribute (set at initialization) indicates whether the MediaWiki API reported the page as a redirect, but it does not indicate the redirect *target*. These methods resolve that target.

### redirects_to()

[mwclient/page.py L110-L119](https://github.com/mwclient/mwclient/blob/47ea5b29/mwclient/page.py#L110-L119)

```

```

Makes an API call using `prop='pageprops'` and `redirects=''` on `self.name`. If the page is a redirect, returns a new `Page` object for the target title. Returns `None` if:

* The page is not a redirect, or
* The API response does not include a redirect entry matching `self.name`.

This always makes a live API call; it does not use any cached data.

## Summary: Key Attributes Affected by text()

After a call to `page.text()`, the following instance attributes may be updated as side effects:

| Attribute | Type | Set when |
| --- | --- | --- |
| `page.last_rev_time` | `time.struct_time` | Always on a successful API fetch (not from cache). Set to `None` if page has no revisions. |
| `page.edit_time` | `time.struct_time` | Only when `expandtemplates=False`. Used as `starttimestamp` on subsequent edits. |
| `page._textcache` | `dict` | Populated if `cache=True`. Cleared after any successful `edit()` / `append()` / `prepend()`. |
