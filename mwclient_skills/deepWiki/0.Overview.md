## What Is mwclient?

mwclient is a Python client library for the [MediaWiki API](https://www.mediawiki.org/wiki/API). It wraps the MediaWiki `api.php` (and, in limited cases, `index.php`) endpoints into a set of Python classes and methods, handling authentication, pagination, retries, and error translation automatically.

| Property | Value |
| --- | --- |
| Language | Python |
| License | MIT |
| PyPI package name | `mwclient` |
| Current stable version | `0.11.0` |
| Minimum Python version | 3.7 |
| Minimum MediaWiki version | 1.21 |
| External runtime dependencies | `requests`, `requests-oauthlib` |

Version compatibility is enforced at runtime: calling a method that requires a newer MediaWiki than the connected wiki provides raises a `MediaWikiVersionError`. See [Error Handling](/mwclient/mwclient/6-error-handling) for the full exception hierarchy.

## Package Modules at a Glance

The package lives entirely under the `mwclient/` directory. The table below summarises each module's responsibility.

| Module | Primary exports | Role |
| --- | --- | --- |
| `mwclient/client.py` | `Site`, `__version__` | Entry point for connecting to a wiki; all API calls originate here |
| `mwclient/page.py` | `Page` | Represents a single wiki page; read, edit, move, delete |
| `mwclient/listing.py` | `List`, `GeneratorList`, `PageList`, `Category`, `PageProperty`, `RevisionsIterator` | Lazy, paginated iterators over API result sets |
| `mwclient/image.py` | `Image` | Extends `Page` with file-specific operations |
| `mwclient/errors.py` | `MwClientError` and subclasses | Full exception hierarchy |
| `mwclient/sleep.py` | `Sleepers`, `Sleeper` | Exponential back-off retry logic |
| `mwclient/util.py` | `handle_limit`, `parse_timestamp` | Shared utility functions |
| `mwclient/types.py` | Type aliases | Typing support |

The package's top-level `__init__.py` re-exports `Site` and everything from `errors` via a star import, so users only need `import mwclient` to access both.

## Project History

mwclient was originally written by **Bryan Tong Minh** and released in 2008 on Sourceforge. Bryan maintained the project through version 0.6.5 (released May 2011).

In 2013, **Waldir Pimenta** coordinated the migration from Subversion to Git and moved the repository to GitHub.

**Dan Michael O. Heggø** became lead maintainer and drove the 0.7.0 release in 2014 — the first release after a three-year gap — and remained lead maintainer through version 0.10.1 (2020).

From 2023, the project has been maintained by **Marc Trölitzsch**, **Adam Williamson**, and **Megan Cutrofello**.

## Versioning Policy

The project follows [Semantic Versioning](https://semver.org/). The authoritative version string is stored in `mwclient/client.py` as `__version__` and is read by the `hatchling` build backend via the `[tool.hatch.version]` configuration in `pyproject.toml`.
