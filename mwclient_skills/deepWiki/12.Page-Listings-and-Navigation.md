This page documents all listing methods available on the `Page` class that return iterable objects for navigating a page's relationships: its incoming links, outgoing links, categories, embedded media, templates, and more. It covers the return types for each method and explains the `generator` parameter pattern that controls what those iterables yield.

For iteration internals (pagination, continue tokens, chunk sizes), see [Iteration and Pagination](/mwclient/mwclient/5-iteration-and-pagination). For reading page content and revision history, see [Reading Page Content](/mwclient/mwclient/3.1-reading-page-content). For site-level listing methods such as `allpages` and `search`, see [Site-Level Listing and Query Methods](/mwclient/mwclient/2.5-site-level-listing-and-query-methods).

## Method Overview

All listing methods on `Page` are defined in [mwclient/page.py L447-L691](https://github.com/mwclient/mwclient/blob/47ea5b29/mwclient/page.py#L447-L691)

 They construct and return iterator objects from [mwclient/listing.py](https://github.com/mwclient/mwclient/blob/47ea5b29/mwclient/listing.py)

 None of them fetch data immediately; all are lazy — data is fetched in chunks only as the iterator is consumed.

There are two distinct return type families depending on which underlying API mechanism is used:

| Family | API mechanism | `generator=True` return type | `generator=False` return type |
| --- | --- | --- | --- |
| `prop`-based | `action=query&prop=...` | `PagePropertyGenerator` | `PageProperty` |
| `list`-based | `action=query&list=...` | `GeneratorList` | `List` |
| Fixed `PageProperty` | `action=query&prop=...` | *(no generator option)* | `PageProperty` |

What you get when you iterate also differs:

* **Generator mode** (`PagePropertyGenerator` or `GeneratorList`): yields fully instantiated `Page`, `Image`, or `Category` objects (namespace-dispatched).
* **Non-generator mode** (`PageProperty` or `List`): yields raw scalar values — typically title strings, or tuples for cross-wiki links.

## Individual Method Details

### backlinks()

[mwclient/page.py L447-L474](https://github.com/mwclient/mwclient/blob/47ea5b29/mwclient/page.py#L447-L474)

Lists pages that contain a wikilink pointing to the current page. Equivalent to `Special:WhatLinksHere`.

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `namespace` | `int` or `str` or `None` | `None` | Restrict results to this namespace |
| `filterredir` | `str` | `'all'` | `'all'`, `'redirects'`, or `'nonredirects'` |
| `redirect` | `bool` | `False` | If `True`, also list pages that link here via a redirect |
| `generator` | `bool` | `True` | If `True`, yield `Page`/`Image`/`Category` objects |
| `max_items` | `int` or `None` | `None` | Maximum total items to yield |
| `api_chunk_size` | `int` or `None` | `None` | Items per API request |
| `limit` | `int` or `None` | `None` | Deprecated alias for `api_chunk_size` |

Uses API prefix `bl`. The page title is passed as `bltitle` (or `gbltitle` in generator mode).

### categories()

[mwclient/page.py L476-L504](https://github.com/mwclient/mwclient/blob/47ea5b29/mwclient/page.py#L476-L504)

Lists categories that the current page is a member of.

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `generator` | `bool` | `True` | If `True`, yield `Category` objects; if `False`, yield title strings |
| `show` | `str` or `None` | `None` | `'hidden'` or `'!hidden'` to filter by hidden status |

Uses API prefix `cl`. This is a `prop`-based query, so `PagePropertyGenerator` or `PageProperty` is returned, not `GeneratorList`/`List`.

### embeddedin()

[mwclient/page.py L506-L540](https://github.com/mwclient/mwclient/blob/47ea5b29/mwclient/page.py#L506-L540)

Lists pages that transclude (embed) the current page. Most commonly used to find pages that use a given template.

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `namespace` | `int` or `str` or `None` | `None` | Restrict results to this namespace |
| `filterredir` | `str` | `'all'` | `'all'`, `'redirects'`, or `'nonredirects'` |
| `generator` | `bool` | `True` | If `True`, yield page objects |
| `max_items` | `int` or `None` | `None` | Maximum total items to yield |
| `api_chunk_size` | `int` or `None` | `None` | Items per API request |
| `limit` | `int` or `None` | `None` | Deprecated alias for `api_chunk_size` |

Uses API prefix `ei`. The page title is set as `eititle`/`geititle`.

### extlinks()

[mwclient/page.py L542-L548](https://github.com/mwclient/mwclient/blob/47ea5b29/mwclient/page.py#L542-L548)

Lists external (off-wiki) URLs referenced by the current page. Always returns a `PageProperty`. No `generator` option exists.

Iterating yields raw URL strings (the `'*'` field from the API response).

Uses API prefix `el`.

[mwclient/page.py L550-L562](https://github.com/mwclient/mwclient/blob/47ea5b29/mwclient/page.py#L550-L562)

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `generator` | `bool` | `True` | If `True`, yield `Image` objects; if `False`, yield title strings |

Uses API prefix `''` (empty — the MediaWiki `images` prop has no parameter prefix). This is a `prop`-based query.

### iwlinks()

[mwclient/page.py L564-L571](https://github.com/mwclient/mwclient/blob/47ea5b29/mwclient/page.py#L564-L571)

Lists interwiki links from the current page (links to other wikis using interwiki prefixes). Always returns a `PageProperty`. No `generator` option.

Iterating yields `(prefix, title)` tuples, where `prefix` identifies the target wiki (e.g. `'wikt'` for Wiktionary) and `title` is the page name on that wiki.

Uses API prefix `iw`.

### langlinks()

[mwclient/page.py L573-L581](https://github.com/mwclient/mwclient/blob/47ea5b29/mwclient/page.py#L573-L581)

Lists interlanguage links from the current page (links to the same article in other languages). Always returns a `PageProperty`. No `generator` option.

Iterating yields `(lang, title)` tuples, where `lang` is the BCP 47 language code and `title` is the page name.

Accepts `**kwargs` which are passed through to the `PageProperty` constructor and on to the API.

Uses API prefix `ll`.

### links()

[mwclient/page.py L583-L603](https://github.com/mwclient/mwclient/blob/47ea5b29/mwclient/page.py#L583-L603)

Lists internal wikilinks from the current page to other pages on the same wiki.

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `namespace` | `int` or `str` or `None` | `None` | Restrict results to this namespace |
| `generator` | `bool` | `True` | If `True`, yield page objects; if `False`, yield title strings |
| `redirects` | `bool` | `False` | If `True`, resolve redirects |

### templates()

[mwclient/page.py L676-L691](https://github.com/mwclient/mwclient/blob/47ea5b29/mwclient/page.py#L676-L691)

Lists templates transcluded on the current page.

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `namespace` | `int` or `str` or `None` | `None` | Restrict results to this namespace |
| `generator` | `bool` | `True` | If `True`, yield page objects; if `False`, yield title strings |

## prop-Based vs list-Based: Structural Difference

The two method families have meaningfully different behavior in how they load data.

**`prop`-based** methods (`categories`, `images`, `links`, `templates`, `extlinks`, `iwlinks`, `langlinks`) use `PageProperty` or `PagePropertyGenerator`. Their `set_iter` implementation [mwclient/listing.py L376-L381](https://github.com/mwclient/mwclient/blob/47ea5b29/mwclient/listing.py#L376-L381)

 searches the API response for the specific page by title and iterates only over that page's property array. Multiple pages could theoretically be in the same response, but these iterators filter to just their own page.

**`list`-based** methods (`backlinks`, `embeddedin`) use `List` or `GeneratorList`. Their data comes from the `list` or `generator` query parameter. The `set_iter` implementation [mwclient/listing.py L131-L138](https://github.com/mwclient/mwclient/blob/47ea5b29/mwclient/listing.py#L131-L138)

 iterates directly over the top-level result array.

## Namespace-Based Dispatch in Generator Mode

When any method is used in generator mode, `GeneratorList.__next__` [mwclient/listing.py L201-L207](https://github.com/mwclient/mwclient/blob/47ea5b29/mwclient/listing.py#L201-L207)

 inspects the `ns` field of each result and instantiates the appropriate class:

| Namespace ID | Returned object |
| --- | --- |
| `14` | `Category` |
| `6` | `mwclient.image.Image` |
| anything else | `mwclient.page.Page` |

This means iterating over `page.categories(generator=True)` yields `Category` objects, while `page.links(generator=True)` over a mixed-namespace page yields a mix of `Page`, `Image`, and `Category` objects as appropriate.

## Pagination and Limits

All listing methods support lazy pagination through the `List.load_chunk` mechanism [mwclient/listing.py L98-L129](https://github.com/mwclient/mwclient/blob/47ea5b29/mwclient/listing.py#L98-L129)

 Continue tokens from the MediaWiki API are automatically appended to subsequent requests.

For methods that accept `max_items` and `api_chunk_size`:

* `max_items`: total items yielded before `StopIteration` is raised.
* `api_chunk_size`: how many items the API is asked for per request (maps to `{prefix}limit` in the query).
* `limit`: deprecated parameter that maps to `api_chunk_size` via `handle_limit` [mwclient/util.py](https://github.com/mwclient/mwclient/blob/47ea5b29/mwclient/util.py)

If `max_items` is set but `api_chunk_size` is not, `List.__init__` [mwclient/listing.py L52-L54](https://github.com/mwclient/mwclient/blob/47ea5b29/mwclient/listing.py#L52-L54)

 automatically sets the chunk size to `min(max_items, site.api_limit)` to avoid fetching unnecessary data.

Methods that do not expose `max_items`/`api_chunk_size` (`categories`, `images`, `links`, `templates`, `extlinks`, `iwlinks`, `langlinks`) still paginate automatically but cannot be configured with an item cap.
