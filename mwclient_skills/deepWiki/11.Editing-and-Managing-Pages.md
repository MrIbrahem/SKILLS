## Permission Checking: can()

Before any write operation, mwclient calls `page.can(action)` to compare the page's protection state against the current user's rights.

**Implementation** ([mwclient/page.py L148-L161](https://github.com/mwclient/mwclient/blob/47ea5b29/mwclient/page.py#L148-L161)

):

1. Look up the protection level for `action` in `self.protection`. If the action is not in `protection`, the level defaults to the action string itself (e.g., `'edit'`).
2. If the level is `'sysop'`, it is remapped to `'editprotected'` (MediaWiki's canonical right name).
3. Return `level in self.site.rights`.

The `protection` dict is populated during `Page.__init__` from the `inprop=protection` API response ([mwclient/page.py L81-L85](https://github.com/mwclient/mwclient/blob/47ea5b29/mwclient/page.py#L81-L85)

). Its structure is:

## Editing Content

### Public Editing Methods

`edit()`, `append()`, and `prepend()` all delegate to the private `_edit()` method, differing only in which keyword argument they pass:

| Method | Kwarg passed to `_edit()` |
| --- | --- |
| `edit(text, ...)` | `text=text` |
| `append(text, ...)` | `appendtext=text` |
| `prepend(text, ...)` | `prependtext=text` |

`save()` ([mwclient/page.py L224-L226](https://github.com/mwclient/mwclient/blob/47ea5b29/mwclient/page.py#L224-L226)

) is a backward-compatibility alias for `edit()`.

All four accept these shared parameters:

| Parameter | Type | Default | Effect |
| --- | --- | --- | --- |
| `text` | `str` | *(required)* | Page content or delta |
| `summary` | `str` | `''` | Edit summary |
| `minor` | `bool` | `False` | Mark as minor edit (sends `minor=1` or `notminor=1`) |
| `bot` | `bool` | `True` | Mark as bot edit (sends `bot=1`) |
| `section` | `Optional[str]` | `None` | Target section number or `'new'` |
| `**kwargs` | `Any` | — | Passed directly to the API call |

Sources: [mwclient/page.py L228-L265](https://github.com/mwclient/mwclient/blob/47ea5b29/mwclient/page.py#L228-L265)

### The _edit() Internal Method

`_edit()` ([mwclient/page.py L267-L336](https://github.com/mwclient/mwclient/blob/47ea5b29/mwclient/page.py#L267-L336)

) is the single implementation behind all edit variants. Its execution has three phases:

**Phase 1 — Pre-flight checks** ([mwclient/page.py L270-L275](https://github.com/mwclient/mwclient/blob/47ea5b29/mwclient/page.py#L270-L275)

):

1. If `site.logged_in` is `False` and `site.force_login` is `True` → raise `AssertUserFailedError`.
2. If `site.blocked` is truthy → raise `UserBlocked(site.blocked)`.
3. If `page.can('edit')` is `False` → raise `ProtectedPageError(self)`.

**Phase 2 — Build request and call API** ([mwclient/page.py L277-L302](https://github.com/mwclient/mwclient/blob/47ea5b29/mwclient/page.py#L277-L302)

):

The `data` dict is built with the following logic:

| Condition | API parameter added |
| --- | --- |
| `minor=True` | `minor='1'` |
| `minor=False` | `notminor='1'` |
| `last_rev_time` is set | `basetimestamp` (from `page.text()` call) |
| `edit_time` is set | `starttimestamp` (from `page.text()` call) |
| `bot=True` | `bot='1'` |
| `section` is not `None` | `section=section` |
| `site.force_login=True` | `assert='user'` |

The inner `do_edit()` closure calls `site.post('edit', title=self.name, summary=summary, token=self.get_token('edit'), **data)`.

**Phase 3 — Error recovery and state update** ([mwclient/page.py L304-L336](https://github.com/mwclient/mwclient/blob/47ea5b29/mwclient/page.py#L304-L336)

):

* On `APIError` with code `'badtoken'`: force-refresh the token and retry `do_edit()` once.
* On other `APIError`: delegate to `handle_edit_error()`.
* On success: update `exists`, `name`, `pageid`, `revision`, `contentmodel`, `last_rev_time`, `touched`.
* Clear `_textcache` to force re-fetch on next `text()` call.
* Clear any `PostEditRevision` cookies (workaround for Phabricator T211233) ([mwclient/page.py L328-L332](https://github.com/mwclient/mwclient/blob/47ea5b29/mwclient/page.py#L328-L332) ).

### Timestamps and Edit Conflict Prevention

`_edit()` sends two optional timestamps that MediaWiki uses to detect edit conflicts:

* **`basetimestamp`** — timestamp of the revision that was read when `page.text()` was last called. Stored as `page.last_rev_time`. MediaWiki rejects the edit if the page has been edited since this timestamp.
* **`starttimestamp`** — time when the client started editing. Stored as `page.edit_time` (set to `time.gmtime()` inside `text()` when `expandtemplates=False`).

Both timestamps are absent if `text()` was never called, which is the case for new pages.

## Managing Pages

### touch()

`touch()` ([mwclient/page.py L352-L360](https://github.com/mwclient/mwclient/blob/47ea5b29/mwclient/page.py#L352-L360)

) performs a "null edit" by calling `self.append('')`. It does nothing if the page does not exist. Its purpose is to trigger re-evaluation of stored data (e.g., Semantic MediaWiki properties, Cargo table values) as opposed to `purge()`, which only updates the page's rendered output.

### move()

`move()` ([mwclient/page.py L362-L402](https://github.com/mwclient/mwclient/blob/47ea5b29/mwclient/page.py#L362-L402)

) renames a page via the `action=move` API.

**Parameters:**

| Parameter | Type | Default | Effect |
| --- | --- | --- | --- |
| `new_title` | `str` | *(required)* | Target page title |
| `reason` | `str` | `''` | Move reason logged in the log |
| `move_talk` | `bool` | `True` | Also move the talk page |
| `no_redirect` | `bool` | `False` | Suppress redirect creation (requires admin) |
| `move_subpages` | `bool` | `False` | Also move subpages |
| `ignore_warnings` | `bool` | `False` | Suppress API warnings |

**Pre-flight:** calls `can('move')`, raises `InsufficientPermission` on failure.

**Post-move state:**

* If `'redirectcreated'` is in the API response: `page.redirect = True`.
* Otherwise (when `no_redirect=True` was used): `page.exists = False`.

Sources: [mwclient/page.py L362-L402](https://github.com/mwclient/mwclient/blob/47ea5b29/mwclient/page.py#L362-L402)

 [test/test_page.py L279-L332](https://github.com/mwclient/mwclient/blob/47ea5b29/test/test_page.py#L279-L332)

### delete()

`delete()` ([mwclient/page.py L404-L434](https://github.com/mwclient/mwclient/blob/47ea5b29/mwclient/page.py#L404-L434)

) deletes a page via the `action=delete` API.

**Parameters:**

| Parameter | Type | Default | Effect |
| --- | --- | --- | --- |
| `reason` | `str` | `''` | Deletion reason |
| `watch` | `bool` | `False` | Add to watchlist |
| `unwatch` | `bool` | `False` | Remove from watchlist |
| `oldimage` | `Optional[str]` | `None` | Specific old image version to delete |

**Pre-flight:** calls `can('delete')`, raises `InsufficientPermission` on failure.

**Post-delete state:** sets `page.exists = False`.

Sources: [mwclient/page.py L404-L434](https://github.com/mwclient/mwclient/blob/47ea5b29/mwclient/page.py#L404-L434)

 [test/test_page.py L251-L277](https://github.com/mwclient/mwclient/blob/47ea5b29/test/test_page.py#L251-L277)

### purge()

`purge()` ([mwclient/page.py L436-L442](https://github.com/mwclient/mwclient/blob/47ea5b29/mwclient/page.py#L436-L442)

) forces MediaWiki to re-render the page by invalidating its parser cache. It uses `site.post('purge', titles=self.name)`. No permission check is performed.

## Error Handling

### Pre-flight Errors

These are raised by `_edit()` (or `move()` / `delete()`) before any API call is made:

| Error class | Triggered by |
| --- | --- |
| `AssertUserFailedError` | `site.logged_in==False` and `site.force_login==True` |
| `UserBlocked` | `site.blocked` is truthy |
| `ProtectedPageError` | `page.can('edit')` returns `False` |
| `InsufficientPermission` | `page.can('move')` or `page.can('delete')` returns `False` |

### API Error Routing in handle_edit_error()

`handle_edit_error()` ([mwclient/page.py L338-L350](https://github.com/mwclient/mwclient/blob/47ea5b29/mwclient/page.py#L338-L350)

) maps API error codes from `APIError.code` to specific Python exceptions:

| API error code(s) | Exception raised |
| --- | --- |
| `'editconflict'` | `EditError(page, summary, info)` |
| `'protectedtitle'`, `'cantcreate'`, `'cantcreate-anon'`, `'noimageredirect-anon'`, `'noimageredirect'`, `'noedit-anon'`, `'noedit'`, `'protectedpage'`, `'cascadeprotected'`, `'customcssjsprotected'`, `'protectednamespace-interface'`, `'protectednamespace'` | `ProtectedPageError(page, code, info)` |
| `'assertuserfailed'` | `AssertUserFailedError()` |
| *(anything else)* | Re-raises original `APIError` |
